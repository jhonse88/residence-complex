# Next.js Project

This is a [Next.js](https://nextjs.org) project bootstrapped with
[`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 🚀 Getting Started

### 1. Install dependencies

To install all project dependencies, run:

``` bash
pnpm install
```

This will generate the `node_modules` folder required by the project.

### 2. Run the development server

Start the development server with:

``` bash
pnpm run dev
```

Once running, open the following URL in your browser:

http://localhost:3000

You can begin editing the project by modifying the file:

    app/page.tsx

The page will automatically update as you make changes.
